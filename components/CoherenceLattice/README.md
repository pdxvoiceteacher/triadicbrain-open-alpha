# CoherenceLattice component projection

This directory is a bounded private projection of selected CoherenceLattice
source used by the Triadic Brain review route. It is not the complete upstream
repository and does not establish complete upstream capability, production
readiness, legal compliance, live-provider acceptance, or public-release
authority.

Within the accepted architecture, CoherenceLattice owns canonical ingress,
grounding and evidence bindings, claim/evidence linkage, selected measurements,
and replay-oriented coordination. It does not issue final truth, manufacture a
Sophia disposition or Atlas posture, authorize publication or memory writes, or
self-approve a candidate. The root private demo does not invoke this inherited
live route.

## Review boundary

Only the source and tests present in this private projection are in scope.
Missing upstream modules, tools, formal assets, providers, and workflows are not
implicitly available or accepted. Hashes and schemas support integrity checks;
they do not certify truth. Public release remains on HOLD and runtime authority
remains `NONE`.
