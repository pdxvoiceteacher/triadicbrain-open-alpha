
# Triadic Brain — investor one-page

## Problem

AI can produce persuasive language without preserving a dependable chain from
source to claim, policy, audit, human decision, and later correction.

## Product thesis

Triadic Brain is a local-first governed AI review workbench that turns model
work into an inspectable candidate and receipt rather than asking people to
trust a fluent answer.

## Architecture

```text
source + task
→ Sonya model/tool boundary
→ CoherenceLattice grounding and candidate binding
→ Sophia independent audit
→ Atlas bounded review posture
→ human approve / hold / reject / repair
→ receipt
→ optional governed memory only after separate consent
```

## What exists today

- Public development source under explicit license and notice boundaries.
- A deterministic provider-free fixture demo.
- A foreground loopback-only review page.
- Canonical request, grounding, candidate, audit, posture, and receipt
  contracts.
- A deeper fixed substantive task through more of the inherited governed route.
- Cross-platform Python 3.12 CI.
- Reproducible wheel and source distributions in the reviewed build.
- No formal GitHub Release, package publication, Pages site, or hosted service.

## What the current demo proves

- Candidate generation and audit are separate roles.
- The auditor cannot silently rewrite the candidate.
- Orientation is not authority.
- The human decision remains separate.
- Exact artifact bytes can be checksum-verified and replayed.
- Failure and HOLD states are valid outputs.

## What remains unfinished

- Arbitrary user document and task intake through the root product.
- Captured-candidate review through the root product.
- Human decision capture and bounded repair in the root UI.
- Approved live local-model adapters.
- Persistent governed PMR memory.
- One-click installation and completed usability/accessibility studies.
- Formal release review.

## Investable thesis

> The opportunity is not another model that claims to be truthful. It is an
> interoperable control and evidence layer that makes model work more
> inspectable, revisable, governable, and accountable while preserving human
> authority.
