# Triadic Brain

## Local AI work you can inspect before you trust

Triadic Brain is UVLM's local-first governed AI review workbench and bounded
cognitive-engine architecture. It separates model generation, source evidence,
policy enforcement, independent review, memory posture, telemetry, and human
authority.

The goal is not to make an AI “truthful” by declaration. The goal is to make AI
work easier to inspect, challenge, repair, reproduce, and govern.

## Current status — public development alpha

The source repository is publicly visible and cloneable. No formal GitHub
Release, package publication, hosted service, or production deployment has been
created.

### Implemented and tested

- deterministic provider-free review fixture;
- canonical request and grounding artifacts;
- candidate packet with source lineage;
- independent non-rewrite audit architecture;
- bounded Atlas review posture;
- human-decision boundary;
- observable trace and receipt contracts;
- checksum-closed export and exact replay;
- loopback-only local review surface;
- Windows and Linux Python 3.12 CI;
- explicit license, third-party, contributor, and AI-assistance disclosures.

### Implemented in the deeper source route

- real grounding-bundle construction;
- claim/evidence mapping;
- deterministic Sophia audit;
- Atlas posture generation;
- sealed route and exact replay;
- raw-versus-governed comparison;
- bounded human review workflow.

### Not yet an ordinary-user root capability

- arbitrary document selection;
- user-defined task and captured-candidate intake;
- live local-model invocation;
- root human decision submission and repair;
- persistent PMR memory;
- one-click installer;
- general provider conformance;
- production deployment.

### Research—not product claims

- coherence as a validated universal cognition metric;
- relational/coherence compression gains;
- GUFT as established cross-domain science;
- AI consciousness, personhood, or autonomous moral authority.

## What the alpha demonstrates

```text
request
→ source evidence
→ candidate
→ independent audit
→ bounded posture
→ human decision
→ receipt
```

A receipt records what happened. It does not certify truth.
