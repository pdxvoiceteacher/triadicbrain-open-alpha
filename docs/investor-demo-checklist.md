
# Investor demo checklist

## Before

- [ ] Use CPython 3.12.
- [ ] Use an independently reviewed wheel.
- [ ] Verify the wheel SHA-256 from the candidate handoff.
- [ ] Use a fresh output directory.
- [ ] Use only the packaged synthetic fixture.
- [ ] Close private files and unrelated terminals.
- [ ] Disable notifications.
- [ ] Do not start a model provider for appearance.

## Run

- [ ] `triadicbrain doctor`
- [ ] `triadicbrain investor-demo --output .\review-run-investor --open-browser`
- [ ] Confirm the browser uses `127.0.0.1`.
- [ ] Show `/status`.
- [ ] Stop the foreground server with `Ctrl+C`.

## Say

- [ ] Candidate is not answer.
- [ ] Receipt is not truth.
- [ ] The root route is a deterministic fixture.
- [ ] No live model was invoked.
- [ ] The root fixture did not execute inherited Sophia or Atlas.
- [ ] The human decision remains separate.
- [ ] The source repository is public, but there is no formal release.
- [ ] The next milestone is real user-selected document review.

## Do not say

- [ ] Truth certification.
- [ ] Compliance certification.
- [ ] General intelligence or consciousness.
- [ ] Persistent memory is active.
- [ ] Every model is compatible.
- [ ] Production deployment is accepted.
- [ ] The public repository is a formal product release.

## After

- [ ] Preserve the run directory.
- [ ] Record date, operator, audience, commit, and wheel hash.
- [ ] Do not publish a run containing anything beyond the synthetic fixture.
