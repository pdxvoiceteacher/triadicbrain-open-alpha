# Roadmap

The roadmap separates completed engineering surfaces from evidence and decisions
that remain outside OA-01. It is not a release promise.

## Private alpha-staging candidate

- **[IMPLEMENTED]** Exact-source projection from the authenticated TriadicGate
  commit into a case-sensitive local repository.
- **[IMPLEMENTED]** One root `triadicbrain` command surface for doctor, an
  offline deterministic contract fixture, and foreground loopback review.
- **[DEFERRED]** Root-wheel invocation of the inherited Coherence/Sophia/Atlas
  implementation route; the current fixture demonstration is not that evidence.
- **[IMPLEMENTED]** Approachable documentation, claim ledger, lineage, rights,
  and notice evidence surfaces.
- **[PROPOSED]** Independent exact-hash review of the final local candidate and
  its test/build evidence.

The review handoff, not this roadmap, controls whether each required gate passed
in a particular build.

## Human decisions required before any public alpha

- **[DEFERRED]** File-level rights-holder attestation for every projected file.
- **[DEFERRED]** Resolution of third-party excerpts, dependencies, notices, and
  inherited SPDX/project-level notice tensions.
- **[DEFERRED]** Selection of an outbound license by the authorized human after
  legal/counsel review.
- **[DEFERRED]** Exact-hash authorization for a private GitHub push.
- **[DEFERRED]** Separate exact-hash public-alpha review and publication decision.

## Evidence still requiring separate execution

- **[DEFERRED]** Live local-provider acceptance under explicit provider
  authorization.
- **[DEFERRED]** Windows clean-machine product acceptance; a CI definition alone
  is not acceptance.
- **[PROPOSED]** Human usability and accessibility studies of the bounded review
  flow.
- **[PROPOSED]** Documentation rendering and link checks in the target release
  environments.

## Research kept outside the ordinary path

- **[RESEARCH]** Advanced mathematical interpretations and formal models.
- **[RESEARCH]** GUFT, 432/Atlas, sacred-geometry, and historical telemetry
  narratives.
- **[DEFERRED]** PMR retention, federation, training, autonomous action, and
  automatic publication.

See the [research index](research/index.md) for the non-product posture.
