# Contributing to the private staging candidate

This repository is private review material. It has no configured public remote,
no selected outbound license, and no authorization for public contributions,
push, publication, deployment, or release.

## Before proposing a local change

1. Obtain a bounded human instruction naming the scope.
2. Preserve the authenticated source and projection lineage.
3. Read the root and applicable nested `AGENTS.md` files.
4. State the expected authority effect; it must remain `NONE` unless a separate
   human commission explicitly changes it.
5. Identify whether the change is inherited, replaced, or OA-01 generated.
6. Disclose human contributors, AI assistance, copied excerpts, dependencies,
   and third-party material.

Submitting or discussing a change does not grant the project any rights. Do not
include material unless the authorized human can review its provenance and
redistribution terms.

## Engineering expectations

- Keep candidate, audit, posture, and human-decision roles separate.
- Candidate is not answer; receipt/hash is not truth.
- Do not add provider calls, PMR writes, federation, training, automatic
  publication, autonomous action, or remote serving to this bounded route.
- Preserve deterministic fixtures and failure receipts.
- Add focused contract and negative tests; no required skip is green.
- Validate casefold paths, wheel members, packaged resources, privacy, secrets,
  absolute paths, documentation links, and clean installs.
- Record exact environments and raw logs. A workflow definition is not platform
  acceptance.

## Rights and release

Update the rights matrix, third-party findings, notice plan, and claim ledger for
every changed path. Do not add or select a root `LICENSE` without a separately
signed exact-hash human rights-and-license decision. Do not configure a remote or
push this repository under OA-01.
