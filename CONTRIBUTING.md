# Contributing to the public development candidate

This repository is a publicly visible implementation and review surface, not a
formal GitHub Release, published package, hosted service, or production
deployment. Public visibility and the operative RL-01 decision do not by
themselves authorize a merge, formal release, package publication, deployment,
provider invocation, or memory write. Every change still needs bounded human
scope and review.

## Before proposing a local change

1. Obtain a bounded human instruction naming the exact scope and authority.
2. Preserve authenticated source, projection lineage, notices, and license
   boundaries.
3. Read the root and applicable nested `AGENTS.md` files.
4. Identify every human identity, AI-assisted surface, dependency, copied
   excerpt, data source, and third-party term relevant to the change.
5. Do not assume a pull request, commit, Git history, or repository ownership
   grants inbound rights.
6. Keep formal-release readiness on HOLD until a separate exact-candidate review
   and authorization changes it; do not describe that HOLD as revoking the
   license terms attached to public files.

## Engineering expectations

- Keep candidate, audit, posture, and human-decision roles separate.
- Candidate is not answer; receipt or hash is not truth.
- Preserve the no-provider, no-memory-write, no-package-publication,
  loopback-only, and source-stability boundaries.
- Add focused positive and negative tests; no required skip is green.
- Validate casefold paths, package members, notices, license hashes,
  deterministic builds, privacy, secrets, links, and clean installs.
- Record exact environments and raw logs.

## Rights and licensing

Contributions intended for inclusion must identify their human contributor,
provenance, AI assistance, inbound terms, and authority. The project license
scope is described in [LICENSE_SCOPE.md](LICENSE_SCOPE.md). Unicode-derived UCD
data remains under Unicode License V3. AI systems are not contributors or
rightsholders. All 166 rights rows remain HOLD pending formal-release and
provenance review.
